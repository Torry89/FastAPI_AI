# Task Manager API

REST API для управления задачами, реализованное на FastAPI.

## Запуск

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Сервер запустится на `http://localhost:8000`.

## Интерактивная документация

- **Swagger UI**: http://localhost:8000/docs
- **ReDoc**: http://localhost:8000/redoc

## API Endpoints

### POST /task

Создание новой задачи.

**Тело запроса (JSON):**

| Поле | Тип | Обязательное | Описание |
|------|-----|-------------|----------|
| title | string | Да | Заголовок (3–100 символов) |
| description | string | Нет | Описание (по умолчанию "") |
| priority | integer | Нет | Приоритет 1–5 (по умолчанию 1) |

**Ответы:**

| Код | Описание |
|-----|----------|
| 201 | Задача успешно создана |
| 422 | Ошибка валидации входных данных |

### GET /task/{task_id}

Получение задачи по идентификатору.

**Параметры пути:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| task_id | integer | Уникальный идентификатор задачи |

**Ответы:**

| Код | Описание |
|-----|----------|
| 200 | Задача найдена |
| 404 | Задача не найдена |

## Модели данных

### TaskCreate

Модель для создания задачи.

| Поле | Тип | Описание |
|------|-----|----------|
| title | string | Заголовок (3–100 символов) |
| description | string | Описание |
| priority | integer | Приоритет 1–5 |

### TaskResponse

Модель ответа с данными задачи.

| Поле | Тип | Описание |
|------|-----|----------|
| id | integer | Уникальный идентификатор |
| title | string | Заголовок |
| description | string | Описание |
| priority | integer | Приоритет 1–5 |
| completed | boolean | Статус выполнения |

## Ошибки

| Код | Endpoint | Причина |
|-----|----------|---------|
| 404 | GET /task/{task_id} | Задача не найдена |
| 422 | POST /task | title отсутствует / < 3 символов / > 100 символов |
| 422 | POST /task | priority вне диапазона 1–5 |
| 422 | POST /task | priority не число |
